# XSUS 官网落地页

XSUS 官方品牌落地页（`https://vpnxsus.cfd`）- 高性能电竞硬件风格机场与网络加速品牌官网。

## 技术栈
- **Framework**: Astro v4 / v5
- **Styling**: Tailwind CSS
- **SEO**: Structured Data (JSON-LD), Semantic HTML5, Sitemap, Robots.txt, Open Graph, Web App Manifest

## 本地开发与构建
```bash
# 安装依赖
npm install

# 启动本地开发
npm run dev

# 编译生产版本
npm run build

# 本地预览构建产物
npm run preview
```
